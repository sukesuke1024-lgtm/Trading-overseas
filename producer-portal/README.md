# H-LINK 生産者ポータル

生産者の皆さまが、日々の **注文・出荷・在庫・売上・精算** を確認するためのポータル（出荷・売上管理ダッシュボード）。PC／スマホ対応。**依存パッケージなし**（Node.js 20 以上だけで動きます）。

## 画面

ホーム（受注件数・出荷予定・今月の売上・振込予定額／売上推移／直近の注文）、注文管理（状態を進める）、出荷管理（カレンダー・印刷）、商品管理（登録・編集・削除）、在庫管理（更新・安全在庫アラート）、売上管理、精算・振込（明細CSV）、トレーサビリティ（ロット登録）、お知らせ（未読バッジ）、サポート（問い合わせ）、パスワード変更、ログアウト。

## 起動

```bash
cd producer-portal
npm start                      # http://127.0.0.1:3100
npm test                       # セキュリティ・業務ロジックのテスト（14件）
```

初回起動時に `data/db.json` を作り、**初期パスワードをコンソールに1回だけ表示**します（`PORTAL_INITIAL_PASSWORD` で指定も可）。デモ生産者は `P000123`（山田農園）と `P000124`（佐藤果樹園）。初回ログイン時にパスワード変更が必須です。

| 環境変数 | 内容 |
|---|---|
| `PORT` / `HOST` | 待受ポート（既定 3100）/ アドレス（既定 127.0.0.1） |
| `NODE_ENV=production` | Cookie に `Secure`、HSTS を付与（HTTPS のリバースプロキシ配下で運用） |
| `PORTAL_TRUST_PROXY=1` | `X-Forwarded-For` をクライアントIPとして使う（プロキシ配下のみ） |
| `PORTAL_DB` | データファイルの場所 |

## セキュリティ対策

- **認証**：パスワードは scrypt（ソルト付き）で保存。ID の有無で応答・処理時間を変えない（ID 列挙対策）。10文字以上・英数字必須。初回は強制変更。
- **総当たり対策**：5回失敗でアカウントを15分ロック＋IPごとのログイン試行制限（429）。API 全体にもレート制限。
- **セッション**：推測不能な乱数トークン（サーバーにはハッシュのみ保存）、`HttpOnly`・`SameSite=Strict`（本番は `Secure`）。30分無操作／12時間で失効。ログインごとに再発行（固定化対策）。ログアウトで即失効。パスワード変更で他端末も失効。
- **CSRF**：変更系 API は CSRF トークン必須＋ Origin 検証。
- **XSS**：画面は `textContent` のみで描画。CSP（`script-src 'self'`・インライン禁止・`frame-ancestors 'none'`）、`X-Content-Type-Options`、`Referrer-Policy`、`Permissions-Policy` ほか。
- **認可**：データはセッションの生産者IDに紐づく分だけ。他社のデータには到達できません（クライアントから生産者IDを受け取らない）。
- **入力**：型・範囲・長さを全項目サーバー側で検証、本文 64KB 制限、`Content-Type` 検査。CSV は数式インジェクション対策。静的配信はパストラバーサル対策。
- **監査ログ**：ログイン・ロック・変更操作を記録（IP つき）。データファイルは `0600`。

## 制約（デモ版）

データは JSON ファイル1つ、セッションはメモリ上（再起動で全員ログアウト）です。複数台構成や本番運用ではデータベース化、TLS 終端、パスワード再発行フロー、二要素認証の追加を推奨します。サンプルの社名・数値はすべて架空です。
