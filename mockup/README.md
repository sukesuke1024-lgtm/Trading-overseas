# H-LINK モックアップ（スクロール物語型）(mockup/)

参考サイト（unitedcarriers.com）の構成を、H-LINK の内容で再現したモックアップ。`index.html` をブラウザで開くと動きます。

- 白黒基調。スクロールでクレーンがコンテナを持ち上げ、トラックに載せ、トラックが走り出す（GSAP + ScrollTrigger）
- 黒い「サービス」帯、道路を走る真上視点のトラック、青い海を進む貨物船、飛行機つきの問い合わせ、の順に場面が移る
- 見出しのグリッチ演出、速度表示、スマホでは画面が動きに合わせて横にパン
- 乗り物はすべてコード上で描いたイラスト（写真は使っていません）
- ロゴは H-LINK 既存サイト案のものを使用（`img/logo-dark.png` は明るい背景用、`img/logo-light.png` は暗い背景用、`img/mark.png` はファビコン）。ナビは背景の明暗に合わせて自動で切り替わります
- 問い合わせフォームは `hp/` と同じ（確認画面からメール作成）。`CONTACT_EMAIL` を差し替えてください

参考サイトには直接アクセスできなかったため、画面録画から読み取れた構成と雰囲気を元にしています。雰囲気（白黒基調、スクロールで進む乗り物の物語、大きな見出し）だけを参考にし、文言・画像・イラスト・ロゴは参考サイトのものを使っていません。乗り物はすべてこちらで描いたオリジナルです。書体は Google Fonts（オープンライセンス）です。
