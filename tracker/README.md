# H-LINK 統合トラッカー

海上コンテナ・航空貨物・国内宅配（ヤマト／佐川／日本郵便）・国際宅配（EMS／DHL／UPS）を、**番号を貼るだけ・1画面・同じ工程バー**で追跡する社内アプリ。ブラウザ側は依存ライブラリなし。

## 起動
```bash
cd tracker
npm start                          # 手入力モード  → http://localhost:8080
TRACK17_KEY=xxxx npm start         # 宅配（国内・国際）を自動取得（17TRACK）
npm test                           # ロジックのテスト（Node 20+）
```
自動取得するには、画面右上「設定」で中継サーバーURL（上記のURL）を入れます。APIキーはサーバーの環境変数にだけ置き、ブラウザには置きません。

## 運用の考え方（個人でも人が増えても同じ）
1. **入力は番号1つだけ**：貼り付けて Enter → 輸送手段・運送会社を自動判別 → 出発地／到着地／ロットを足して保存。
2. **見るのは例外だけ**：画面上部の「今日の要対応」（ETA超過・配送の問題・フリータイム切れ・動きなし・番号不正）だけ毎朝確認。
3. **全手段を同じ7工程**に正規化（手配→集荷→出発→輸送中→到着→通関／配達中→完了）。
4. **ロットで紐付け**：同じロットの海・空・宅配の荷物がまとめて見える（トレーサビリティ）。
5. **間違いは入力時に止める**：コンテナ（ISO 6346）・AWB・ヤマト・国際郵便(S10)の検査数字を検証。
6. **バックアップ**：データはブラウザ内。「バックアップ」でJSON保存（1週間以上空くと画面で警告）。CSV取込・JSON復元に対応。

## 輸送手段ごとの状況
| 手段 | 判別 | 自動取得 |
|---|---|---|
| 国内宅配・国際宅配 | 番号形式で自動 | **17TRACK 連携を実装**（`server/relay.js`）。※模擬応答で動作確認済み。実APIでの検証は未実施 |
| 海上コンテナ | コンテナ番号（検査数字つき） | 未接続（ShipsGo 等の契約後、`PROVIDERS.sea` に追加） |
| 航空貨物 | AWB 11桁（検査数字つき）。航空会社名を表示 | 未接続（同上、`PROVIDERS.air`）。便の位置は将来対応 |

未接続の手段は、手入力＋「次の工程へ」ボタン＋CSVで運用できます（地図の位置は出発日〜ETAからの推定の目安）。

## セキュリティ
- 中継サーバーは `TRACKER_TOKEN` を設定すると `/api/*` に Bearer トークンが必須。配信するファイルは4つに限定。
- 社内LAN／VPN内で使ってください。インターネットへ直接公開しないでください。
- 荷物データ（取引先名など）はサーバーに送らず、ブラウザ内にのみ保存します。送るのは追跡番号だけです。
