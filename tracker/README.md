# H-LINK コンテナ追跡

コンテナ輸送の「荷物が今どこにあるか」を一覧・地図・工程バーで確認する追跡アプリ。依存ライブラリなし（静的HTML/JS）。

```bash
cd tracker
python3 -m http.server 8080   # → http://localhost:8080
npm test                      # ロジックのテスト（Node 20+）
```

## できること
- コンテナ登録・編集・削除（ISO 6346 チェックデジット検証、船会社の判別）
- 7工程（ブッキング→搬入→積込→航海中→到着→通関→配送）の進捗バーと、積港〜揚港の地図（出港〜ETAからの推定位置）
- 遅延（ETA超過）・到着間近・フリータイム／デマレージのアラート
- ロット・生産者・取引先の紐付け（トレーサビリティ連携用）
- CSV 取込／出力（取込は同じコンテナ番号を上書き）。データはブラウザ内に保存

## 次の段階（実位置の自動取得）
実際の船位・イベントは船会社／追跡API（ShipsGo、Terminal49 等。有料・API契約が必要）から取得します。
APIキーをブラウザに置かないよう、社内サーバー側の中継（プロキシ）を作り、`core.js` と同じ形式の項目（stage / eta / vessel）で返す想定です。契約先が決まり次第実装します。
