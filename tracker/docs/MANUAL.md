# H-LINK 荷物追跡 使い方

海上コンテナ、航空貨物、国内宅配（ヤマト・佐川・日本郵便）、国際宅配（EMS・DHL・UPS）を、**1つの画面で同じ見方**で確認する社内アプリです。

> **基本の考え方**：入力は追跡番号だけ。毎朝見るのは「ダッシュボードの要対応」だけ。変更は全員分、操作履歴に残ります。

## 0. ログインとログアウト

1. 管理者から **社員ID** と **仮パスワード** を受け取る。
2. 画面のURLを開き、社員IDとパスワードを入れて **ログイン**。
3. 初めてのときは、パスワードの変更画面が出ます。自分だけが知るパスワードに変更してください（10文字以上、英字と数字を含む。IDを含めたり、同じ文字だけにはできません）。変更するまで他の機能は使えません。
4. 使い終わったら、左下の **ログアウト** を押す。共有のパソコンでは必ずログアウトしてください。

- **2時間操作しないと自動でログアウト**されます。最長でも12時間でログアウトされます。データは保存済みなので消えません。
- **5回続けてパスワードを間違えると15分間ロック**されます。急ぐときは管理者に「ロック解除」を依頼してください。
- パスワードを忘れたら、管理者に「パスワード再発行」を依頼してください。仮パスワードが発行され、初回と同じ手順で再設定します。
- パスワードの変更は **設定** からいつでもできます。変更すると、他の端末のログインは解除されます。

### 権限
| できること | 一般 | 管理者 |
|---|---|---|
| 荷物の登録・編集・次の工程へ・最新に更新 | ○ | ○ |
| 荷物の一括取り込み・書き出し | ○ | ○ |
| 荷物の削除 | × | ○ |
| ユーザーの追加・権限変更・パスワード再発行・無効化 | × | ○ |
| 操作履歴の確認 | × | ○ |

## 1. 毎日の使い方（5分）

1. 左のメニュー **ダッシュボード** を開く。
2. 「今日の要対応」に出ている荷物を上から順に確認する。赤が緊急、黄色が注意。
3. 行をクリックすると詳細が開く。取引先や運送会社に連絡が必要なら対応する。
4. 対応が済んだ荷物は、状態が進めば自動で要対応から消える。

要対応が0件なら、その日の確認は終わりです。

## 2. 荷物を登録する

1. **荷物一覧** を開く。
2. 上の入力欄に追跡番号を貼り付けて Enter。
3. 輸送手段と運送会社が自動で入る。出発地・到着地・ETA・ロット・取引先を足して **保存**。

| 輸送手段 | 追跡番号の例 | 判別のしかた |
|---|---|---|
| 海上コンテナ | `CSQU3054383` | 英字4文字＋数字7桁 |
| 航空貨物 | `131-2345678-6` | 数字11桁（AWB）。先頭3桁で航空会社を表示 |
| 国内宅配 | `100000000004` | 12桁はヤマトまたは佐川。11桁は佐川・日本郵便 |
| 国際宅配 | `1Z...`、`EE123456785JP` | UPS、国際郵便、DHL（10桁） |

- 番号の検査数字が合わないと、入力欄の下に赤い注意が出ます。**入力ミスのことが多い**ので、元の伝票と見比べてください。
- 同じ番号は二重に登録されません。すでにある番号を入力すると、その荷物が開きます。
- 11桁などは複数の手段に当てはまることがあります。判別が違っていたら「輸送手段」を選び直してください。

### ロット番号は必ず入れる
ロット番号は、生産者・商品・出荷をつなぐ共通のキーです。`AITREK OS` のロット番号と同じものを入れてください。同じロットの荷物（海・空・宅配）は詳細画面にまとめて表示され、リコールや問い合わせのときに「このロットはどこか」をすぐ引けます。

## 3. 画面の見方

### 状態（7つの工程）
全ての手段で同じ7工程です。表示名だけ手段ごとに変わります。

| 工程 | 海上 | 航空 | 宅配 |
|---|---|---|---|
| 1 | ブッキング済 | 手配済 | 受付済 |
| 2 | 積地ターミナル搬入 | 空港受付 | 集荷 |
| 3 | 本船積込 | 搭載・出発 | 発送 |
| 4 | 航海中 | 飛行中 | 輸送中 |
| 5 | 揚地到着 | 到着 | 配達店到着 |
| 6 | 通関中 | 通関中 | 配達中 |
| 7 | 配送完了 | 配達完了 | 配達完了 |

一覧の小さな7つの四角は進み具合です。赤が現在の工程です。

### 要対応になる条件
| 表示 | 意味 | することの例 |
|---|---|---|
| ETA を○日超過 | 到着予定日を過ぎても到着していない | 船会社・フォワーダーに確認し、ETAを更新 |
| 配送上の問題 | 追跡サービスが不達・例外を報告 | 運送会社に連絡 |
| フリータイム終了 | 無料の保管期間が終わった（デマレージ発生） | 早急に引き取り手配 |
| ○日間、動きがありません | 一定期間、更新がない（海5日・空2日・国内3日・国際5日） | 状況を問い合わせ |
| 到着まであと○日 | 3日以内に到着 | 受け入れ準備 |
| 番号の形式が不正 | 検査数字が合わない | 番号を見直す |

### 地図
海上・航空の詳細に出ます。赤い丸が現在位置です。**追跡サービスに接続していない間は、出発日からETAまでの経過で位置を推定した目安**です。実際の位置ではありません。

## 4. 状態の更新

### 自動で取得できる手段（宅配）
左下の **最新に更新** を押すと、輸送中の荷物の最新状態を取得します。ログイン中は30分ごとに自動でも取得します。状態・到着予定・配送の問題が変わると、そのまま保存され、要対応にも反映されます。

### 手入力の手段（海上・航空は契約待ち）
- 詳細画面の **次の工程へ** を押すと、状態が1つ進みます。
- ETAや本船は **編集** から直します。

## 5. 管理者の作業

### 起動と初期設定（最初の1回）
```bash
cd tracker
npm install
npm run build
TRACK17_KEY=（17TRACKのキー） COOKIE_SECURE=1 npm start
```
1. 初回起動時、画面に **初期管理者のIDとパスワードが一度だけ表示** されます。控えてください（`TRACKER_ADMIN_ID` / `TRACKER_ADMIN_PASSWORD` で指定もできます）。
2. 表示されたURL（例 `http://192.168.1.20:8080`）を開いてログイン。初回にパスワードを変更します。
3. https のURLで公開する場合は `COOKIE_SECURE=1` を付けてください。リバースプロキシの後ろに置く場合は `TRUST_PROXY=1` も付けます。
4. APIキー（`TRACK17_KEY`）はサーバーの環境変数にだけ置きます。画面やブラウザには入れません。

### ユーザーを追加する（入社）
**ユーザー管理** →「ユーザーを追加」に社員ID・氏名・権限を入れて追加。表示された **仮パスワードは一度しか出ません**。本人に口頭か対面で伝えてください（メールやチャットに残さない）。

### 退社・異動・困りごと
| 状況 | 操作 |
|---|---|
| 退社した | 「無効にする」。ログイン中でもその場でログアウトされます |
| パスワードを忘れた | 「パスワード再発行」→ 仮パスワードを本人へ |
| ロックされた | 「ロック解除」 |
| 担当が変わった | 「管理者にする」「一般にする」 |

自分自身は無効にできません。最後の管理者は、無効化も一般への変更もできません。

### 操作履歴
**ユーザー管理** の下部に、ログイン・ログイン失敗・ロック・荷物の登録/更新/削除・ユーザー操作が、いつ・誰が・何を、の形で残ります（パスワードは記録されません）。見覚えのないログイン失敗が続くときは、そのIDのパスワードを再発行してください。

> 社内LANまたはVPNの中だけで使ってください。インターネットに直接公開しないでください。
> 追跡サービスに送られるのは追跡番号だけです。取引先名・ロットなどは外に出ません。

## 6. データの保管とバックアップ

荷物データとユーザー情報は **サーバーの `data` フォルダ** に保存されます（`shipments.json`、`users.json`、`audit.log`）。

- 管理者は、`data` フォルダを **毎日または毎週、別の場所へコピー** してください。サーバーが壊れたときの唯一の復元手段です。
- パスワードは暗号化（scrypt）して保存され、管理者にも元の文字列は分かりません。
- 一覧は **設定** の「書き出し（JSON）」「CSV出力」でも保存できます。Excelで作った一覧は「取り込み」で一括登録できます（同じ追跡番号は上書き）。

## 7. 人が増えたとき

- 運用ルールは変えません。「番号を貼る→ロットを入れる→朝は要対応だけ見る」で足ります。
- 人が増えたら、ユーザー管理で追加するだけです。全員が同じデータを見ます（60秒ごとに自動で反映）。
- 同じ荷物を同時に編集すると、後から保存した内容が残ります。誰がいつ変えたかは操作履歴で確認できます。

## 8. よくある質問

**番号を入れたのに輸送手段が違う。** 11桁・12桁は複数の手段に当てはまります。「輸送手段」を選び直してください。

**海上の状態が自動で進まない。** 海上・航空の自動取得は未接続です（契約待ち）。「次の工程へ」で進めてください。

**地図の位置が実際と違う。** 実績位置が取得できていない間は推定の目安です。

**急にログイン画面に戻った。** 2時間操作がなかった、または管理者がアカウントを無効にした可能性があります。入力中のものは保存前だと消えるので、こまめに保存してください。

**他の人が登録した荷物が出てこない。** 60秒ごとに自動で取得します。すぐ見たいときはページを再読み込みしてください。

**削除ボタンが出ない。** 削除は管理者のみです。管理者に依頼してください。取り消しはできません（管理者はサーバーの `data` のバックアップから戻せます）。

## 9. 用語

| 用語 | 意味 |
|---|---|
| AWB | 航空運送状番号。航空貨物の追跡番号（11桁） |
| B/L | 船荷証券。海上貨物の書類番号 |
| HAWB | フォワーダーが発行する航空の分割運送状 |
| ETD / ETA | 出発予定 / 到着予定 |
| フリータイム | コンテナを無料で置いておける期間 |
| デマレージ | フリータイムを過ぎたときの超過料金 |
| ロット | 同じ生産者・同じ製造単位でまとめた商品の番号 |
