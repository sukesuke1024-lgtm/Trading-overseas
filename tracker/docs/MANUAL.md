# H-LINK 荷物追跡 使い方

海上コンテナ、航空貨物、国内宅配（ヤマト・佐川・日本郵便）、国際宅配（EMS・DHL・UPS）を、**1つの画面で同じ見方**で確認する社内アプリです。

> **基本の考え方**：入力は追跡番号だけ。毎朝見るのは「ダッシュボードの要対応」だけ。

## 1. 毎日の使い方（5分）

1. 左のメニュー **ダッシュボード** を開く。
2. 「今日の要対応」に出ている荷物を上から順に確認する。赤が緊急、黄色が注意。
3. 行をクリックすると詳細が開く。取引先や運送会社に連絡が必要なら対応する。
4. 対応が済んだ荷物は、状態が進めば自動で要対応から消える。

要対応が0件なら、その日の確認は終わりです。

## 2. 荷物を登録する

1. **荷物一覧** を開く。
2. 上の入力欄に追跡番号を貼り付けて Enter。
3. 輸送手段と運送会社が自動で入る。出発地・到着地・ETA・ロット・取引先を足して **保存**。

| 輸送手段 | 追跡番号の例 | 判別のしかた |
|---|---|---|
| 海上コンテナ | `CSQU3054383` | 英字4文字＋数字7桁 |
| 航空貨物 | `131-2345678-6` | 数字11桁（AWB）。先頭3桁で航空会社を表示 |
| 国内宅配 | `100000000004` | 12桁はヤマトまたは佐川。11桁は佐川・日本郵便 |
| 国際宅配 | `1Z...`、`EE123456785JP` | UPS、国際郵便、DHL（10桁） |

- 番号の検査数字が合わないと、入力欄の下に赤い注意が出ます。**入力ミスのことが多い**ので、元の伝票と見比べてください。
- 同じ番号は二重に登録されません。すでにある番号を入力すると、その荷物が開きます。
- 11桁などは複数の手段に当てはまることがあります。判別が違っていたら「輸送手段」を選び直してください。

### ロット番号は必ず入れる
ロット番号は、生産者・商品・出荷をつなぐ共通のキーです。`AITREK OS` のロット番号と同じものを入れてください。同じロットの荷物（海・空・宅配）は詳細画面にまとめて表示され、リコールや問い合わせのときに「このロットはどこか」をすぐ引けます。

## 3. 画面の見方

### 状態（7つの工程）
全ての手段で同じ7工程です。表示名だけ手段ごとに変わります。

| 工程 | 海上 | 航空 | 宅配 |
|---|---|---|---|
| 1 | ブッキング済 | 手配済 | 受付済 |
| 2 | 積地ターミナル搬入 | 空港受付 | 集荷 |
| 3 | 本船積込 | 搭載・出発 | 発送 |
| 4 | 航海中 | 飛行中 | 輸送中 |
| 5 | 揚地到着 | 到着 | 配達店到着 |
| 6 | 通関中 | 通関中 | 配達中 |
| 7 | 配送完了 | 配達完了 | 配達完了 |

一覧の小さな7つの四角は進み具合です。赤が現在の工程です。

### 要対応になる条件
| 表示 | 意味 | することの例 |
|---|---|---|
| ETA を○日超過 | 到着予定日を過ぎても到着していない | 船会社・フォワーダーに確認し、ETAを更新 |
| 配送上の問題 | 追跡サービスが不達・例外を報告 | 運送会社に連絡 |
| フリータイム終了 | 無料の保管期間が終わった（デマレージ発生） | 早急に引き取り手配 |
| ○日間、動きがありません | 一定期間、更新がない（海5日・空2日・国内3日・国際5日） | 状況を問い合わせ |
| 到着まであと○日 | 3日以内に到着 | 受け入れ準備 |
| 番号の形式が不正 | 検査数字が合わない | 番号を見直す |

### 地図
海上・航空の詳細に出ます。赤い丸が現在位置です。**追跡サービスに接続していない間は、出発日からETAまでの経過で位置を推定した目安**です。実際の位置ではありません。

## 4. 状態の更新

### 追跡サービスに接続していないとき（手入力）
- 詳細画面の **次の工程へ** を押すと、状態が1つ進みます。
- ETAや本船は **編集** から直します。

### 接続しているとき
左下の「更新」で最新を取得します。中継サーバーのURLを設定している間は、30分ごとに自動で取得します。宅配は自動で状態が進みます。海上・航空は、追跡サービスの契約後に自動取得できます。

## 5. 接続の手順（管理者向け）

APIキーはブラウザではなく、サーバーにだけ置きます。

```bash
cd tracker
npm install
npm run build
TRACK17_KEY=（17TRACKのキー） TRACKER_TOKEN=（任意の長い文字列） npm start
```

1. 起動したサーバーのURLを社内で開く（例 `http://192.168.1.20:8080`）。
2. **設定** →「追跡サービスとの接続」にトークンを入力して保存。
3. 中継サーバーのURL欄に、手順1のアドレスを入れて保存（自動更新はこのURLを入れたときだけ動きます）。

> 社内LANまたはVPNの中だけで使ってください。インターネットに直接公開しないでください。
> 追跡サービスに送られるのは追跡番号だけです。取引先名・ロットなどは外に出ません。

## 6. バックアップと引っ越し

荷物データは**このブラウザの中**に保存されています。別のパソコンやブラウザには引き継がれません。

- **設定** →「バックアップ（JSON）」を **週1回** 保存してください。1週間以上空くと画面上部に注意が出ます。
- 新しいパソコンでは「取り込み」でJSONを読み込めば復元できます。
- Excelで作った一覧は、列名を `CSV出力` の1行目に合わせれば「取り込み」で一括登録できます。

## 7. 人が増えたとき

- 運用ルールは変えません。「番号を貼る→ロットを入れる→朝は要対応だけ見る」で足ります。
- 複数人で同じデータを見る場合は、ブラウザ保存ではなくサーバー保存への移行が必要です。管理者に相談してください。
- 誰がいつ何を変えたかを残す履歴機能も、サーバー保存への移行と同時に追加します。

## 8. よくある質問

**番号を入れたのに輸送手段が違う。** 11桁・12桁は複数の手段に当てはまります。「輸送手段」を選び直してください。

**海上の状態が自動で進まない。** 海上・航空の自動取得は未接続です（契約待ち）。「次の工程へ」で進めてください。

**地図の位置が実際と違う。** 接続前は推定の目安です。実際の位置は、追跡サービス接続後に実績値へ切り替わります。

**画面を閉じたらデータが消えた。** ブラウザの履歴・サイトデータを消すと消えます。バックアップから「取り込み」で戻せます。

**削除を取り消せる？** 取り消せません。削除は2回押しで確定します。迷ったらバックアップを先に取ってください。

## 9. 用語

| 用語 | 意味 |
|---|---|
| AWB | 航空運送状番号。航空貨物の追跡番号（11桁） |
| B/L | 船荷証券。海上貨物の書類番号 |
| HAWB | フォワーダーが発行する航空の分割運送状 |
| ETD / ETA | 出発予定 / 到着予定 |
| フリータイム | コンテナを無料で置いておける期間 |
| デマレージ | フリータイムを過ぎたときの超過料金 |
| ロット | 同じ生産者・同じ製造単位でまとめた商品の番号 |
