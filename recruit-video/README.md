# 海外バイヤー・海外営業 採用動画（90秒）

採用ページ・説明会・SNSで使える、海外バイヤーと海外営業の仕事紹介動画です。

- 完成動画: [`out/overseas-buyer-sales-recruit-90s.mp4`](out/overseas-buyer-sales-recruit-90s.mp4)（1920×1080 / 30fps / H.264 + AAC / 90秒）
- サムネイル: [`out/poster.jpg`](out/poster.jpg)
- ナレーションなし・テロップ中心の構成です（採用ページでは自動再生時にミュートになるため、音声なしでも内容が伝わるようにしています）。
- BGMは `bgm.py` で合成したオリジナル曲なので、著作権の心配はありません。

## 編集・再書き出し

テキストやタイミングは `index.html` を直接編集します（各要素の `data-t="表示開始秒,終了秒"` で出し入れを制御）。
ブラウザで `index.html` を開くとリアルタイムでプレビューできます。

```bash
pip install numpy imageio-ffmpeg     # ffmpeg がない場合
python3 bgm.py                       # BGM を生成 -> out/bgm.wav
node render.cjs                      # 動画を書き出し -> out/overseas-buyer-sales-recruit-90s.mp4
node render.cjs --company "株式会社〇〇"   # 最後のエントリー画面に会社名を入れる
node render.cjs --from 13 --to 33 --out out/buyer.mp4   # 一部だけ書き出し（SNS用の切り出しなど）
```

Playwright（Chromium）と ffmpeg が必要です。
