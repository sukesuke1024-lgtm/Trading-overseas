# H-LINK 会社ホームページ (hp/)

問い合わせを増やすことを目的にした、1ページ完結の静的サイト（HTML/CSS/JS のみ、ビルド不要）。`index.html` をブラウザで開くと動きます。

## 設計
- 方向性: 夜明けの映像のようなダークデザイン。写真が色を持ち、アクセントは H-LINK の赤のみ（1テーマで固定）
- 書体: Geist + Zen Kaku Gothic New
- 構成: 浮いたガラスのナビ、全面写真の中央ヒーロー、スクロールで一語ずつ点灯する文、品目の隙間なしベント、固定見出し+立場別の入口、スクロールで線が描かれる流れ図、積み重なる理由カード、4ステップ、FAQ、夕焼けを背景にしたフォーム
- 各カードは二重の枠（外枠+内側）、ボタンは丸い島つきのピル。CTA ラベルは「無料で相談する」に統一
- 動き: GSAP + ScrollTrigger（cdnjs から読み込み）。ヒーローの視差、文字の点灯、写真の拡大、流れ図の描画、カードの積み重ね。読み込めない場合や reduced-motion では静止表示に戻ります
- スマホ: 追従の相談ボタン、メニューは全面オーバーレイ（×に変形するボタン）

## 写真について
`img/` の写真は、既存の H-LINK コーポレートサイト案（claude.ai の Artifact）に入っていた画像を取り出したものです。画像生成（Higgsfield）は無料プランでは使えませんでした。差し替える場合は同名・同比率のファイルを置いてください。

## 公開前に差し替えるもの
- `index.html` 内の `CONTACT_EMAIL`（現在は `hello@example.com`）
- 会社概要（所在地・代表者・連絡先）。未確定のため掲載していません
- 本文の「無料」などの表現は仮の文言です。実際の運用に合わせて確認してください
- 実績・数値・取引先ロゴは入れていません。開示できるものが決まったら追加してください
