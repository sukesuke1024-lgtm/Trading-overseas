# H-LINK 会社ホームページ (hp/)

問い合わせを増やすことを目的にした、1ページ完結の静的サイト（HTML/CSS/JS のみ、ビルド不要）。

- 生産者・メーカー / 海外バイヤーの2導線を、ヒーロー・タブ・フォーム・追従ボタンに通して配置
- 必須項目4つだけのフォーム。サーバーが無いため、確認画面からメールソフトで送信する方式
- ライト/ダーク対応、スマホ幅対応、動きを減らす設定に対応

## 公開前に差し替えるもの
- `index.html` 冒頭のスクリプト内 `CONTACT_EMAIL`（現在は `hello@example.com`）
- 会社概要（所在地・代表者・連絡先）。未確定のため掲載していません
- 本文の「無料」「無理な営業は行いません」等の表現は仮の文言です。実際の運用に合わせて確認してください
- 実績・数値・写真は入れていません。使える素材ができたら追加してください

確認: `index.html` をブラウザで開くだけで動きます。
