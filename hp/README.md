# H-LINK 会社ホームページ (hp/)

問い合わせを増やすことを目的にした、1ページ完結の静的サイト（HTML/CSS/JS のみ、ビルド不要）。`index.html` をブラウザで開くと動きます。

## 設計
- 方向性: B2B コーポレート、写真主導、信頼と問い合わせ導線を重視（UI UX Pro Max の「Trust & Authority + Conversion」パターン、design-taste-frontend の規則に沿って構成）
- 配色: 青みのある白と濃紺、アクセントは H-LINK の赤のみ。ライト/ダーク両対応
- 書体: Geist + Zen Kaku Gothic New（明朝は使わない）
- 構成: スプリットのヒーロー、品目のベント（4セル）、立場別の2つの入口、濃紺の流れ図、固定見出し+理由リスト、4ステップ、FAQ、フォーム
- CTA ラベルは「無料で相談する」に統一。スマホは画面下に追従ボタン
- 動き: 表示時の持ち上がり、画像のゆっくりした拡大、ホバー。reduced-motion では停止

## 写真について
`img/` の写真は、既存の H-LINK コーポレートサイト案（claude.ai の Artifact）に入っていた画像を取り出したものです。画像生成（Higgsfield）は無料プランでは使えませんでした。差し替える場合は同名・同比率のファイルを置いてください。

## 公開前に差し替えるもの
- `index.html` 内の `CONTACT_EMAIL`（現在は `hello@example.com`）
- 会社概要（所在地・代表者・連絡先）。未確定のため掲載していません
- 本文の「無料」などの表現は仮の文言です。実際の運用に合わせて確認してください
- 実績・数値・取引先ロゴは入れていません。開示できるものが決まったら追加してください
