# H-LINK 社内ポータル

H-LINK の社内ポータル（勤怠・申請承認・Excel連携・経理・監査）。
Next.js 16 + Tailwind v4。PC・スマホ（PWA）対応。ログイン + セキュリティコード（TOTP）、勤怠の自動計算つき。

## 2つの動かし方

| モード | 認証 | データ | 用途 |
|---|---|---|---|
| **デモ（static）** | デモ認証（パスワード固定・コード画面表示） | 各端末のブラウザ内 | GitHub Pages で公開・見せる用。`/portal/` で公開 |
| **サーバー（server）** | 社員番号 + パスワード（scrypt）+ 認証アプリのTOTP、5回失敗で15分ロック、CSRF対策、12時間セッション | サーバー上の `data/db.json`。PCとスマホで同期 | 社内LANで実際に使う |

### サーバーモード（同じネットワークのスマホからも勤怠を確認）

```bash
cd portal
npm install
npm run build
npm run start:lan        # 0.0.0.0 で待ち受け、LANのURLを表示（例: http://192.168.1.20:3000）
```

1. PCでもスマホでも、表示されたURLをブラウザで開く（同じWi-Fi/社内LAN）
2. 従業員番号（社長は `001`）と初期パスワード（既定 `Hlink-2026!`。`PORTAL_INITIAL_PASSWORD` で変更可）でログイン
3. 初回のみ QR を認証アプリ（Google/Microsoft Authenticator 等）で読み取り、6桁コードを入力
4. 初期パスワードの変更を求められます（12文字以上・英字/数字/記号）

外出先から使う場合は、社内VPN（または Tailscale 等）経由で同じURLに接続してください。**インターネットへ直接公開しないでください。**
ホーム画面へのインストール（PWA）は https が必要な端末があります（リバースプロキシで https 化）。

環境変数: `PORTAL_DATA_DIR`（データ保存先）, `PORTAL_INITIAL_PASSWORD`, `PORTAL_SESSION_SECRET`（複数台構成時のみ）。

### デモ（GitHub Pages）

`main` へのマージで `.github/workflows/lp.yml` が LP と一緒にビルドし、`/portal/` に公開します（Settings → Pages → Source: GitHub Actions）。
手元で確認: `NEXT_PUBLIC_BASE_PATH= npm run build:static` → `out/`。ログイン画面に社員番号とパスワード、当日のデモ用コードが表示されます。

## 権限（3区分）

| 区分 | 勤怠 | 従業員マスタ | 申請・承認 | 経理・監査 | Excel連携 |
|---|---|---|---|---|---|
| **管理者**（社長＝長尾 晃佑 他） | 全員を閲覧・修正 | 取込・編集・権限設定 | 全件 | 編集可 | 可 |
| **役員** | 全員を閲覧のみ | 閲覧 | 全件 | 閲覧のみ | 不可 |
| **従業員** | 自分のみ入力・閲覧 | 氏名・職種のみ | 自分に関係する申請のみ | 不可 | 不可 |

権限は従業員マスタの「権限」で決まります（社長 001 は常に管理者・最後の管理者は降格不可）。サーバー側でも項目単位で強制します（`src/server/policy.ts`）。

## 勤怠 → Excel → 給与計算

1. 従業員が `/attendance` で日々の始業・終業・休憩を入力（所定 8:30〜17:00・休憩60分、25:00 のような翌日表記も可）。
2. 実労働・所定内・法定内/法定外残業・60h超・深夜・法定休日/法定外休日・休日深夜を、勤怠ブック（勤怠入力_自動計算.xlsx）と同じルールで自動計算（`src/lib/work.ts`）。
3. 管理者が `/excel` で
   - **勤怠ブックに反映**：従業員・休日マスタ・日別勤怠を書き込んだ xlsx をダウンロード（数式・書式はそのまま）
   - **賃金計算ブックに反映**：「⑤勤怠入力」の月・出勤〜フレックス繰越の列を書き込む。⑥賃金計算以降は Excel が自動計算
   - 日別勤怠・月次集計の CSV 出力
4. 従業員マスタは賃金計算ブック「④従業員マスタ」から取り込めます（番号・氏名・職種・雇用区分・所定時間などの**必要最小限だけ**。賃金額・マイナンバーは読みません）。

Excel ファイルは**ブラウザ内だけで処理**され、サーバーにもリポジトリにも保存されません（給与・マイナンバーを含むため）。
給与計算より先（振込・明細配布など）は未定です。

> 勤怠ブックの「深夜」列の式は、24:00〜29:00 を二重計上し、同日 0:00〜5:00 を拾えません。ポータルの計算は正しい値で、必要なら `/excel` の「深夜労働の計算式を修正する」で式を差し替えて出力できます。

## 画面

ホーム（今日の打刻・ToDo）／勤怠／申請・承認／お知らせ／従業員・権限／Excel連携・CSV／決算書・販管費／仕訳帳／監査・税務調査出力／上場準備／監査ログ。

## 複数端末への即時反映（サーバー版）

PC で入力した内容がスマホへ約1秒で反映されます（Server-Sent Events）。デモ版はブラウザ内保存のため対象外です。

## セキュリティ設計（サーバーモード）

- 認証: scrypt パスワード、TOTP二要素（秘密鍵は AES-256-GCM で保存時暗号化）、5回失敗で15分ロック、IPレート制限、TOTPコードの再利用拒否、ログアウト/パスワード変更で全端末のセッション失効
- 認可: **サーバー側で**項目単位に強制（`src/server/policy.ts`）。一般社員のAPI応答に会計・他人の給与・他人の勤怠は含まれず、不正な書き込み（他人の打刻・承認の段階飛ばし・仕訳の改変/削除・締め済み月への計上・自己承認）は拒否してログに記録
- 監査: 操作ログと仕訳はハッシュ連鎖（削除・改変・並べ替えを検出）。監査ログはサーバーが連鎖を計算し、実行者は認証済み本人に固定
- ヘッダー: CSP・X-Frame-Options・nosniff・Referrer-Policy・COOP/CORP、CSRF（Origin検証）、Cookie は HttpOnly/SameSite=Lax（https では Secure）
- CSV: 数式インジェクション対策、Excel向けBOM付きUTF-8

### 限界（本番前に必要なこと）
- 保存先は `data/db.json`（単一サーバー・ファイル）。本番は DB＋定期バックアップ＋監査ログの外部退避、SSO 連携を推奨
- 給与計算そのものは Excel（賃金計算ブック）側で行い、ポータルは⑤勤怠入力までを自動反映します。共有フォルダへの自動同期は未実装
- 会計は簡易版（単一法人・日本基準・円のみ）。決算書は税理士・監査法人の確認が前提
- デモ版（GitHub Pages）は端末内保存・デモ認証（パスワード `Hlink-Demo-2026!`、画面にコード表示）のため、サーバー側の権限強制は働きません

## ロゴ・アイコンの自動生成

`npm run brand` が `brand/src/` の元ロゴから `public/brand/`・PWA/iOS/favicon を生成します。

## 開発

```bash
npm run dev            # http://localhost:3000（開発中はサーバーモード）
npm run dev:lan        # LAN公開つき
npm run lint && npm run typecheck && npm test && npm run build
```

人物・数値のサンプルは架空です（社長名と社名のみ実在）。
