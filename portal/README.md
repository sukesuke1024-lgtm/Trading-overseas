# ミライHD 社内ポータル（デモ）

東証プライム上場の大企業（架空：株式会社ミライホールディングス）の社内ポータルと、業務Webアプリ群を一体化したデモ。
Next.js 16 + Tailwind v4。バックエンド不要（データはブラウザの localStorage に保存）。

## 機能

| 画面 | 内容 |
|---|---|
| ホーム | 重要なお知らせ固定表示、勤怠打刻、ToDo（承認依頼・差戻し・必須研修）、IR情報、会議室、研修進捗 |
| お知らせ | カテゴリ/未読絞り込み、既読管理、管理者による投稿・削除 |
| ワークフロー | 経費精算・休暇・出張・稟議・IT申請。決裁権限表に基づく承認ルート自動生成（金額100万円以上は経営企画部を追加）、承認/差戻し/却下（コメント必須）、取下げ |
| 勤怠 | 打刻、月次集計、休憩控除、時間外の36協定アラート（45h/80h）、有給残 |
| 社員名簿・組織図 | 氏名・部署・スキル・内線で検索、部署別組織図 |
| 文書ライブラリ | 規程・マニュアル・様式・ガイドライン（版数・改定日・主管部署）検索/取得 |
| 会議室予約 | 日別スロット表、ダブルブッキング防止、自分の予約の取消 |
| ヘルプデスク | FAQ検索 + 問い合わせ起票、管理者によるステータス更新 |
| 研修 | 必須（コンプライアンス）/任意コース、期限・進捗管理 |
| 管理・監査ログ | 操作ログ（J-SOX想定）、デモデータ初期化（全社管理者のみ） |
| 全社検索 | `⌘K` / `Ctrl+K`。社員・文書・お知らせ・FAQを横断検索 |

ヘッダーの「表示ロール」で 一般社員 / 承認者 / 全社管理者 を切り替えて権限差を確認できます。

## 開発

```bash
cd portal
npm install
npm run dev      # http://localhost:3000
npm run lint && npm run typecheck && npm run build
```

## 本番化する場合の想定

SSO（SAML/OIDC）・人事マスタ連携（SCIM）・DB（PostgreSQL等）・ファイルストレージ・メール/Teams通知・監査ログの改ざん防止を差し込む前提の構成です。現状のデータ層は `src/lib/store.tsx` に集約しています。
