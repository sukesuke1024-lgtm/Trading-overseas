# H-LINK バイヤーポータル（卸受注ダッシュボード）

国内外のバイヤー向け B2B 受注ダッシュボードのデモ。ビルド不要の静的サイトです。

```
cd buyer && python3 -m http.server 8000   # http://localhost:8000
```

| 画面 | ルート |
|---|---|
| トップ（ダッシュボード・ブランドビジュアル） | `#/` |
| 01 商品検索・カテゴリーフィルター | `#/search` |
| 02 商品詳細・卸価格・在庫・MOQ | `#/product/:id` |
| 03 サンプル依頼フロー（入力、確認、完了） | `#/sample/:id` |
| 04 お気に入り・再注文 | `#/favorites` |
| 05 問い合わせ・チャット | `#/messages` |
| 06 注文・発注履歴・ステータス追跡 | `#/orders` |
| 見積・サンプル依頼 / アカウント設定 | `#/requests` `#/account` |

- データは localStorage に保存（サイドバー下の「デモデータを初期化」で復元）。
- 商品写真は一部のみ。`app.js` の `PRODUCTS` の `img` に画像パスを入れると差し替えできます。

## ログインとセキュリティ（デモ版）

- ログイン画面あり。アカウントは `config.js` の `accounts` に **パスワードのハッシュ(SHA-256)だけ** を保持します（パスワード本体は置きません）。
  追加・変更: `node -e "crypto.subtle.digest('SHA-256',new TextEncoder().encode('salt:ID:パスワード')).then(b=>console.log(Buffer.from(b).toString('hex')))"`（`salt` は `config.js` の値）
- 15分無操作で自動ログアウト、5回連続の失敗で60秒ロック、ログアウトで画面データを破棄。データはIDごとに分けて保存。
- CSP（外部スクリプト禁止）・noindex・referrer なし・外部リンクは `noopener noreferrer`・出力はすべてエスケープ。
- **注意**: 照合はブラウザ内で行うため、ソースを読める人にはハッシュが見えます。本番ではサーバー側認証（パスワード検証・セッション・多要素認証）に置き換えてください。デモデータに機密は入れないでください。

## 多言語・会社サイト・画面操作

- 言語: 日本語 / English / 简体中文（`i18n.js` の辞書。右上のメニューで切替、選択は保存）。トップ写真内の文字は画像のため翻訳されません。
- 会社サイト: `config.js` の `companyUrl` に URL を入れると、右上とメニュー下部にリンクが出ます（空なら非表示）。
- 左上のメニューボタンでサイドメニューを開閉（PCは折りたたみ、スマホはドロワー）。「戻る・進む」ボタンで閲覧したページを行き来。
